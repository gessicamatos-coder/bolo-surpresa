# 🎂 Bolo Surpresa - Página de Aniversário Interativa

Uma página web interativa de aniversário onde você pode "apagar a vela" e assistir uma chuva de confetes! Perfeita para surpreender alguém especial.

## ✨ Funcionalidades

- **Bolo 3D animado**: Camadas que surgem com efeito de "crescimento"
- **Vela interativa**: Clique na chama para apagar
- **Chuva de confetes**: Mais de 300 confetes coloridos com física
- **Design responsivo**: Funciona em qualquer dispositivo
- **Efeitos visuais**: 
  - Chama que tremela (efeito de fogueira)
  - Confetes com rotação e formas variadas (círculos e quadrados)
  - Fundo com desfoque no texto

## 🎮 Como usar

1. Abra a página
2. Clique na **chama da vela** 🔥
3. Veja a mágica acontecer - chuva de confetes e mensagem de parabéns!

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações keyframes, transformações)
- JavaScript puro (Canvas API para confetes)
- Design responsivo

## 🎨 Visual

- Fundo rosa claro (tom pastel)
- Bolo rosa com camadas coloridas
- Vela 3D com sombra
- Confetes coloridos em HSL

## 📱 Compatibilidade

Funciona em todos navegadores modernos (Chrome, Firefox, Safari, Edge)
